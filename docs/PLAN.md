# План KeepYouAwake

Цель – локальная версия KeepingYouAwake с прежним интерфейсом и одной дополнительной настройкой закрытой крышки. Пользователь разрешил разработку и оставил физическую проверку себе в конце.

## Решение

Берём исходники KeepingYouAwake, коммит `2be93dd7f390b23fbca934ff3b1ac03468a80077`. Новый флаг в Advanced действует только во время активной сессии. Вместо постоянного `pmset disablesleep` используем `kPMSetClamshellSleepState` из SDK IOKit. Это недокументированный для прикладных программ интерфейс, поэтому совместимость проверяется на конкретном Маке.

Отдельный непривилегированный процесс удерживает режим и читает канал от приложения. Закрытие канала при обычном выходе или аварийном завершении приложения запускает восстановление сна. Процесс периодически повторяет запрос, поскольку системное управление питанием может сбрасывать флаг. Ошибка процесса отображается в приложении. Команда восстановления доступна отдельно на случай аварийного завершения самого процесса.

Полное переписывание интерфейса увеличивает объём работы. Постоянный системный флаг через `pmset` требует прав администратора и отдельной установки для восстановления. Для личной версии выбран минимальный форк с процессом восстановления.

## Проверки

Тесты процесса используют подмену только вызова IOKit, без изменения питания компьютера. Тесты управления сессией запускают настоящий дочерний процесс с такой подменой. Отдельная проверка настоящего IOKit выполняется с открытой крышкой и немедленным восстановлением. Физическое закрытие крышки не считается проверенным агентом.
